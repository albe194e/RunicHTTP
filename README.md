# RunicHTTP  

## Introduction  

Welcome to **RunicHTTP**!  

RunicHTTP is a lightweight and customizable HTTP server built using the Odin programming language. This project was originally developed to power the website for the [HADL project](https://www.google.dk/) and serves as a robust foundation for creating web servers in Odin.  

Whether you're interested in learning about server development or need a flexible starting point for your own project, RunicHTTP is here to help.  

---

## Current Features  

Currently under active development, **RunicHTTP** has no implemented features yet. Stay tuned for exciting updates as the project evolves!  

---

## Planned Features  

Here’s a glimpse of what’s coming:  
- **Basic HTTP Handling**: Support for GET and POST requests.  
- **Static File Serving**: Efficiently deliver HTML, CSS, and JavaScript files.  
- **Routing System**: Define custom routes and handlers for different endpoints.  
- **Middleware Support**: Add functionality such as logging or authentication.
