# RunicHTTP  

## Introduction  

Welcome to **RunicHTTP**!  

RunicHTTP is a lightweight and customizable HTTP server built using the Odin programming language. This project was originally developed to power the website for the [HADL project](https://www.google.dk/) and as a way for me to develop better Odin skills.

---

## Current Features  

Currently under active development, **RunicHTTP** has no implemented features yet. Stay tuned for exciting updates as the project evolves!  

---

## Planned Features  

Here’s a glimpse of what’s coming:  
- **Basic HTTP Handling**: Support for GET and POST requests.  
- **Static File Serving**: Efficiently deliver HTML, CSS, and JavaScript files.  
- **Routing System**: Define custom routes and handlers for different endpoints.  
- **Middleware Support**: Add functionality such as logging or authentication.
